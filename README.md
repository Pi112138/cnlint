# cnlint
一款专注**中文文档拼写检查 & 规范化排版**的轻量 Lint 工具

## 简介
在撰写中文技术文档、README、博客、知识库、产品文案时，人工极易出现大量细微排版问题：
- 中英文、中文数字之间遗漏空格
- 全角、半角标点混用
- 重复标点符号
- 直角引号、弯引号误用
- 基础中文字词拼写错误

这类问题不影响程序运行，但严重影响**文档专业性、统一规范性、阅读体验**。

**cnlint** 专为中文场景设计，聚焦解决中文文档最常见的几十类不规范写法，开箱即用、轻量无依赖、可本地校验、可接入 CI 自动化检查，帮助团队和个人统一中文排版规范。

## 核心特性
### 1. 中英文排版校验
自动检测并规范中文与英文、中文与数字之间的空格问题：
- 中英文之间缺少分隔空格
- 中英文之间多余无效空格
- 中文数字混排不规范格式

完全遵循国内通用《中文技术文档排版规范》。

### 2. 全角 / 半角标点校验
智能识别上下文场景，自动发现错误标点：
- 中文句子内误用半角标点 `, . ! ?`
- 英文代码片段、参数名中误用全角标点
- 全局标点符号风格混乱、混用不统一

### 3. 重复标点检测
精准识别连续重复的无效标点：
- 连续逗号、句号、感叹号、问号
- 多余顿号、空格标点组合
- 文案手误导致的叠词标点问题

### 4. 引号规范校验（高频痛点）
专门解决中文文档最容易出错的引号问题：
- 中文正文误用直角引号 `"` `'`
- 中英文引号混用混乱
- 统一规范为标准中文弯引号 `“ ” ‘ ’`

### 5. 中文基础拼写检查
内置基础中文词库，检测常见错别字、形近字、常用错误词组，提升文档文字准确性。

### 6. 轻量、快速、无侵入
- 单命令运行，无需复杂配置
- 支持批量文件扫描、目录扫描
- 支持 Markdown / 纯文本等通用文档格式
- 可自由接入 Git 提交校验、CI 自动检查

## 解决的痛点
1. **人工校对成本极高**：长文档逐条排版检查费时费力
2. **团队风格不统一**：多人协作文档排版混乱、规范不一致
3. **现有工具冗余复杂**：大部分 Lint 工具规则过多、配置繁重
4. **中文专属规则缺失**：通用文本校验工具不针对中文排版做优化
